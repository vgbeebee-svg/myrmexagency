# Myrmex Agency homepage

This is a standalone replacement for the repository's root `index.html`, prepared October 12, 2026. Existing company identity, address, business email, privacy email, and legal email were retained from the live website and GitHub source. Existing legal pages and the GitHub Pages CNAME should be retained. Legal links use their existing live URLs so they also work in the local preview.

The page presents website video access and API access for individual creators, small teams, and API businesses. No prices, unverified model capabilities, output examples, official partnerships, or commercial-use guarantees are included. The hero landscape is explicitly labeled as an illustration, not a generated sample.

The contact form opens the visitor's email client with a draft. It does not store leads or send mail from the website. No backend, tracking scripts, keys, cookies, or generation calls are added. Google Fonts is used, as in the existing page, with local system font fallbacks.

To deploy on the existing GitHub Pages site, replace only the root `index.html` in `vgbeebee-svg/myrmexagency` with this file. Preserve `CNAME`, `privacy.html`, `terms.html`, and `copyright.html`. Review the change in a pull request before merging to the branch used by GitHub Pages.
